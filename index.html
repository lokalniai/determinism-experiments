Batch-invariant mode runs only on standard attention. vLLM 0.31 refuses LFM2.5 (short-conv layers) and the Qwen3.6 MoE (W4A16 NVFP4, Gated DeltaNet), so this is the only model it was measured on. The invariant output is fixed, but it is a different computation: it differs from the default batch-1 output on 4 of 5 prompts. At batch size 1, throughput is 118 tok/s by default and 39 tok/s invariant (single request, see the report).
